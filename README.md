# KinoPub для Samsung Smart TV (Tizen)

Неофициальный клиент kino.pub для телевизоров Samsung на Tizen. Управление с пульта,
интерфейс со «стеклянным» эффектом, нативный плеер Samsung AVPlay с 4K, HDR и HEVC.

Проверено на Samsung QE55Q95T (2020, Tizen 5.5, Chromium 69). Должно работать на моделях
Samsung с 2017 года.

> **Это неофициальное приложение.** Оно не связано с kino.pub и не распространяет контент:
> это только клиент к API сервиса. Для просмотра нужна своя подписка kino.pub.

## Возможности

- **Вход по коду.** Телевизор показывает код и адрес (например, `kino.pub/device`), вы вводите код на сайте.
- **Главная как на сайте:** «Продолжить просмотр», популярное, новое и горячее по всем разделам.
- **Каталоги** (фильмы, сериалы, концерты, документальное, ТВ-шоу, 3D):
  - сортировка;
  - несколько фильтров сразу: жанры, страны, годы, возраст;
  - заранее заданное ограничение по возрасту.
- **Возрастной рейтинг** каждого фильма. В API kino.pub он не заполнен, поэтому берётся из
  Wikidata по номеру IMDb. При наведении карточка подсвечивается цветом рейтинга.
- **Карточка фильма:**
  - постер во всю высоту;
  - рейтинги КП и IMDb, описание, актёры и режиссёры;
  - озвучки, трейлер, похожие;
  - закладки, «Буду смотреть», отметка «просмотрено».
- **Сезоны и серии:** прогресс по каждой серии, продолжение с места остановки.
- **«Я смотрю»** сортируется, как «Новые эпизоды» на сайте: сверху сериалы со свежими сериями.
- **Плеер** на нативном Samsung AVPlay:
  - HLS4 с автоматическим выбором качества, 4K, HDR, HEVC;
  - выбор озвучки и субтитров. Форсированные субтитры помечаются, даже если API их не отмечает:
    приложение сравнивает число реплик в дорожках одного языка;
  - автоматический переход к следующей серии;
  - прогресс синхронизируется с сайтом и другими устройствами.
- **Поиск** с экранной клавиатурой в раскладке QWERTY / ЙЦУКЕН и с цифрами.
- **Разделы** «Я смотрю», «Закладки», «История», «Подборки».
- **Подписка и серверы:**
  - в углу экрана видно, сколько дней подписки осталось; за неделю до конца появляется напоминание;
  - рядом индикатор состояния серверов;
  - в настройках есть тест скорости серверов.
- **Настройки** плеера и устройства: 4K, HEVC, HDR, сервер, тип потока.

### Управление с пульта

| Где | Кнопка | Действие |
|---|---|---|
| Везде | Стрелки, OK | Навигация и выбор |
| Везде | Назад | Шаг назад. На главном экране — в меню, затем выход |
| Плеер | OK | Пауза или продолжение |
| Плеер | ← / → | Перемотка: при удержании шаг растёт 10 → 30 → 60 с |
| Плеер | ↑ / ↓ | Панель: озвучка, субтитры, качество |
| Плеер | ⏩ / ⏪ | Перемотка на ±30 с |
| Плеер | CH+ / CH− | Следующая или предыдущая серия |

## Ключ API

API kino.pub ([kinoapi.com](https://kinoapi.com)) авторизует приложения по OAuth
(Device Flow). Для этого нужны данные клиента: `client_id` и `client_secret`. В репозитории
их нет, каждый указывает свои:

1. Скопируйте `js/config.example.js` в `js/config.js`.
2. Впишите в него `clientId` и `clientSecret`. Данные клиента для своего приложения можно
   запросить у поддержки kino.pub.

`js/config.js` указан в `.gitignore` и в репозиторий не попадает. Без него приложение
соберётся, но на экране входа покажет ошибку «не задан ключ API».

## Установка на телевизор

Samsung разрешает ставить свои приложения только в режиме разработчика и только с подписью
сертификатом Samsung. Настройка делается один раз.

> **Tizen Studio больше не поддерживается.** Tizen SDK («Baseline SDK») ставится одним из способов:
> - расширением **Tizen Extension** для VS Code — этот путь описан ниже;
> - расширением **Visual Studio Tools for Tizen**;
> - консольным установщиком `web-cli_Tizen_SDK_<версия>`.
>
> Команды `tizen package` и `tizen install` не изменились, ими пользуется `tools\build.ps1`.

### 1. Tizen Extension и Tizen SDK

1. В VS Code (1.100 или новее) установите **Tizen Extension**, ID `tizen.vscode-tizen-csharp`:
   ```bash
   code --install-extension tizen.vscode-tizen-csharp
   ```
2. При первом запуске расширение спросит путь для Tizen SDK. Укажите путь без пробелов
   и кириллицы, например `C:\tizen-studio`. Расширение само установит Baseline SDK.
3. На панели **Tizen** откройте **Baseline Tools → Package Manager** и на вкладке
   дополнительных пакетов (**Extension SDK** / **Advanced**) установите:
   - **Samsung Certificate Extension** — для сертификата Samsung;
   - **TV Extensions** (Samsung Tizen TV SDK), последнюю версию.

   Менеджеру пакетов нужны права администратора.

### 2. Включите режим разработчика на телевизоре

1. Узнайте IP-адрес компьютера: в PowerShell выполните `ipconfig` и найдите «IPv4-адрес».
2. На телевизоре откройте **Smart Hub** → панель **Apps** (Приложения).
3. Наберите **1 2 3 4 5** на пульте или на экранной цифровой клавиатуре. На пульте без цифр
   нажмите кнопку **123**.
4. Включите **Developer mode**, впишите IP компьютера и нажмите **OK**.
5. Перезагрузите телевизор: держите кнопку питания, пока не появится логотип Samsung.
   После перезагрузки вверху панели Apps появится надпись **Develop Mode**.
6. Узнайте IP телевизора: **Настройки → Общие → Сеть → Состояние сети → Настройки IP**.

### 3. Подключите телевизор

Любым из способов:

- в VS Code: панель **Tizen** → **Device Manager** → **Connect a Remote Device** →
  **Add Devices** → IP телевизора, порт **26101** → **Add** → **Connect**;
- в терминале (вместо `192.168.1.50` — IP телевизора):
  ```bash
  C:\tizen-studio\tools\sdb.exe connect 192.168.1.50
  ```

### 4. Создайте сертификат Samsung

Телевизор должен быть подключён: его идентификатор (DUID) попадёт в сертификат.

1. На панели **Tizen** откройте **Certificate Manager**.
2. **Create a new Certificate** → имя профиля (например, `kp`) → тип **Samsung**.
3. Заполните данные автора: имя и пароль.
4. Для distributor-сертификата выберите уровень **Public** и отметьте DUID телевизора.
5. Войдите в аккаунт Samsung, когда откроется браузер.
6. Сделайте созданный профиль активным.

### 5. Соберите и установите приложение

Сначала создайте `js/config.js` (см. «Ключ API»). Затем в папке проекта выполните
(вместо `192.168.1.50` — IP телевизора):

```bash
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -TvIp 192.168.1.50
```

Скрипт сам найдёт Tizen SDK, подпишет приложение активным профилем, соберёт
`dist\KinoPub.wgt`, установит его и запустит.

- Профиль не выбран как активный? Добавьте `-Profile kp`.
- SDK стоит в нестандартном месте? Добавьте `-TizenHome D:\путь\к\tizen-sdk`.
- Чтобы только собрать `.wgt` без установки, запустите скрипт без `-TvIp`.

### Как поделиться приложением

Подписанный `dist\KinoPub.wgt` установится только на телевизор, DUID которого записан
в сертификате. Чтобы отдать приложение другому человеку, соберите файл без подписи:

```bash
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Unsigned
```

Получится `dist\KinoPub-unsigned.wgt`. В нём нет подписей и идентификатора вашего телевизора,
но **есть ваш `js/config.js`** — учитывайте это, когда передаёте файл. Получатель проходит
шаги 1–4 и подписывает файл своим сертификатом:

```bash
powershell -ExecutionPolicy Bypass -File tools\build.ps1 -Wgt KinoPub-unsigned.wgt -TvIp 192.168.1.50
```

### Проблемы

- **`tizen security-profiles list` пустой, хотя сертификат создан в VS Code.** Certificate
  Manager кладёт сертификат в `C:\Users\<имя>\SamsungCertificate\<профиль>\`, но не всегда
  записывает профиль в `C:\tizen-studio-data\profile\profiles.xml`, откуда его берёт CLI.
  Пропишите его вручную. В поле `password` указывается путь к зашифрованному файлу `.pwd`,
  а не сам пароль:
  ```xml
  <?xml version="1.0" encoding="UTF-8" standalone="no"?>
  <profiles active="kp" version="3.1">
  <profile name="kp">
  <profileitem ca="" distributor="0" key="C:\Users\<имя>\SamsungCertificate\kp\author.p12" password="C:\Users\<имя>\SamsungCertificate\kp\author.pwd" rootca=""/>
  <profileitem ca="" distributor="1" key="C:\Users\<имя>\SamsungCertificate\kp\distributor.p12" password="C:\Users\<имя>\SamsungCertificate\kp\distributor.pwd" rootca=""/>
  <profileitem ca="" distributor="2" key="" password="" rootca=""/>
  </profile>
  </profiles>
  ```
- **Device Manager видит TV, но не подключается.** В режиме разработчика на телевизоре указан
  не тот Host PC IP. Проверьте, с какого адреса компьютер обращается к TV:
  ```bash
  powershell -Command "Find-NetRoute -RemoteIPAddress <IP телевизора> | Select-Object -First 1 IPAddress"
  ```
  Впишите этот адрес в телевизор и полностью перезагрузите его. Если адреса в сети часто
  меняются, закрепите их за компьютером и телевизором в настройках роутера (DHCP-резервирование).
- **`1010 : App install fail` или ошибка подписи.** Чаще всего distributor-сертификат создан
  без DUID этого телевизора. Пересоздайте профиль, пока TV подключён.
- **«You are not an authorized user!».** Обновите прошивку телевизора и расширение VS Code.
- **Видео не запускается.** В **Настройках** приложения смените тип потока на **HLS2** или **HTTP**.
- **USB.** Установку приложений с флешки телевизоры Samsung больше не поддерживают.

## Разработка

Чистый JavaScript без сборки и зависимостей, совместимый с Chromium 69 (Tizen 5.5).
Поэтому в коде нет `?.`, `??`, `gap` у flex, `backdrop-filter` и `aspect-ratio`.

Телевизор рисует страницу программно, без GPU, поэтому интерфейс рассчитан на это:

- прокрутка сделана через `transform`;
- у карточек нет теней и фильтров;
- размытый фон из постера — это сам постер, уменьшенный на canvas и растянутый обратно.

```
config.xml           манифест Tizen
index.html
css/app.css          стили (стекло, ряды, плеер)
js/config.example.js шаблон ключа API → скопировать в js/config.js
js/api.js            API kino.pub (авторизация по коду, перебор зеркал)
js/nav.js            пространственная навигация пультом
js/player.js         плеер: AVPlay на TV, HTML5 в браузере
js/age.js            возрастные рейтинги из Wikidata
js/status.js         подписка и состояние серверов
js/screens/*.js      экраны
tools/build.ps1      подпись, сборка и установка на TV
tools/devserver.py   локальный сервер для отладки в браузере
tools/cdp.py         отладка на телевизоре через DevTools Protocol
```

### Отладка в браузере

```bash
python tools/devserver.py
```

Откройте `http://localhost:8090`. Клавиатура работает как пульт: стрелки, Enter и Esc
вместо «Назад». В браузере вместо AVPlay работает HTML5-видео, поэтому озвучку и 4K
можно проверить только на телевизоре.

### Отладка на телевизоре

```bash
sdb -s <IP>:26101 shell 0 debug KinoPubTV1.KinoPub
sdb -s <IP>:26101 forward tcp:9333 tcp:<порт из вывода>
python tools/cdp.py eval "document.title"
```

`cdp.py` также умеет `file <script.js>`, `shot <file.png>`, `keys Down Enter` (нажатия
пульта) и `click <selector>`.

### Особенности Samsung AVPlay (Tizen 5.5)

- `getTotalTrackInfo` нумерует аудиодорожки с 0, а `setSelectTrack('AUDIO', n)` ждёт номер
  с 1. Каждый вызов блокирует плеер примерно на 0,4 с, а несуществующий номер роняет
  приложение через несколько минут, когда кончится буфер.
- Видео AVPlay рисуется под страницей: во время просмотра у `body` должен быть прозрачный фон,
  а у `<object>` плеера — `visibility: hidden`.
